# Glide 제스처 영상 검토

일곱 영상은 같은 트랙패드와 Windows 창 모형을 사용합니다. 파란 원은 접촉 위치를 나타내며 손을 뗄 때 사라집니다. 창과 원의 위치를 같은 시간에서 계산해 이동과 크기 변화를 나란히 보여줍니다.

- 창 이동은 위치만 바뀌고, 펼치기와 오므리기는 중심을 기준으로 가로·세로가 함께 바뀝니다.
- 방향별 조절에는 대기 시간 1초를 예시로 썼습니다. 대기 중 창은 그대로이며 오른쪽 아래로 민 뒤 두 테두리가 움직입니다.
- 위·좌우 끝에 닿아도 손을 뗄 때까지 창이 최대화되거나 반쪽에 맞지 않습니다. 좌우 배치는 각각 원래 크기로 되돌아오는 장면까지 확인했습니다.
- 빠른 배치의 접촉 시간은 방향마다 0.28초입니다. 위·왼쪽·오른쪽 결과가 차례로 표시됩니다. 실제 속도를 보여주기 때문에 손가락 이동 구간은 짧고 배치 결과는 더 오래 표시됩니다.

HyperFrames 검사와 시작·중간·전환 프레임으로 화면을 확인했습니다. 360px 미리보기에서는 창 안의 작은 조작부보다 제스처 제목과 원의 움직임이 잘 보입니다. 각 영상은 10초 이하의 무음 안내입니다. 한국어 글꼴은 Windows의 맑은 고딕을 사용합니다.

영문 README용 영상은 같은 동작과 길이를 사용합니다. 인트로와 일곱 장면을 영어로 렌더링해 화면 속 제목, 안내 문구, 창 이름이 잘리지 않는지 확인했습니다. 전체 영상은 46.4초이며 처음 4.3초에 인트로가 나옵니다. 두 HyperFrames 컴포지션 모두 검사 오류가 없었습니다. 장면이 한 트랙에 있는 기존 구조에 대해 편집 편의 관련 경고가 남아 있습니다.
