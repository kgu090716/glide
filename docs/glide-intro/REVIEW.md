# Glide 인트로 검토

- 4.3초 동안 실제 Glide 아이콘과 이름, 앱 설명을 보여준다. 세 손가락을 나타내는 원 세 개가 움직이는 동안 창과 커서도 같은 방향으로 이동한다.
- HyperFrames에서 오류가 없었고, 360px 미리보기에서 제품명과 주요 문구를 확인했다. 하단 기능 설명은 짧은 보조 문구로 배치했다.
- 렌더링 결과는 1920×1080, 30fps, 129프레임이다. 전체 영상에서 4.3초 지점에 첫 제스처인 창 이동 장면이 시작되는 것을 확인했다. README에 연결한 960×540 반복 GIF도 디코딩해 확인했다.
- 기존 제스처 영상에 맞춰 오디오를 넣지 않았다. Windows의 맑은 고딕을 사용하는 글꼴 경고와 단일 장면의 HTML 구조 경고가 남아 있다. 최종 영상과 GIF에는 렌더링된 글자가 포함된다.
